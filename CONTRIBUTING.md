# Contributing

Contributions are welcome.

## Before opening a pull request

1. Keep changes focused and small.
2. Avoid third-party dependencies unless clearly necessary.
3. Preserve the package's lightweight SwiftUI Layout API.
4. Add or update tests for wrapping, spacing, or alignment behavior.
5. Run:

```bash
swift build
swift test
```

By contributing, you agree that your contributions will be licensed under this repository's MIT License.
